# Warm Sage

Muted brown surfaces, cream text, and sage accents. A warm dark theme with
readable syntax colors and a coordinated workbench and terminal.

![Warm Sage palette and syntax preview](assets/preview.png)

The image above is a palette and syntax illustration, not an editor screenshot.

## Install

Install **Warm Sage** by **smallhusk** from the Visual Studio Marketplace once
published. Open **Preferences: Color Theme** and choose **Warm Sage**.

For an offline installation, choose **Extensions: Install from VSIX...** and
select the release's `warm-sage-1.0.0.vsix` file.

## Colors

- Muted taupe-brown backgrounds and cream foregrounds.
- Sage functions, strings, focus indicators, and active controls.
- Soft mauve keywords, dusty blue types, and amber numbers.
- Subdued diagnostics and Git decorations.
- TextMate and semantic highlighting, with matching ANSI terminal colors.

Editor preferences, fonts, and file icons are left to your configuration.
Language grammars and language servers determine which syntax tokens are available.

## Also available for Zed
